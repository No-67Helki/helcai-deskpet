# 真实桌宠素材生产规范

## 目标

从同一主体的多视角照片建立稳定身份特征，再生成姿态一致、透明背景、脚点统一的多帧桌宠资源。运行时只播放成品帧，不在用户桌面上临时调用云模型。

## 生产阶段

1. 输入检查：确认正面、左右侧面、坐姿、休息姿和脸部细节齐全。
2. 身份建模：记录毛色、花纹、脸型、眼睛、耳朵、尾巴和体型特征。
3. 姿态生成：分别生成待机、行走、坐下、睡眠、互动和拖拽状态。
4. 一致性筛选：淘汰花纹漂移、肢体错误、体型变化和镜像错误的帧。
5. 透明化与边缘修复：保留毛发半透明边缘，不使用全图颜色删除。
6. 对齐与打包：统一画布、比例、脚点、朝向、FPS，输出 PetManifest v2。
7. 自动校验与视觉验收：通过资源校验器后才能导入 DeskCat。

## 最低动画要求

| 状态 | 建议帧数 | 行为 |
| --- | ---: | --- |
| idle | 12 / 8 FPS | 脚点固定；呼吸、一次眨眼、尾尖微动 |
| walk | 16 / 16 FPS | 接触、下沉、交替跨步和抬升完整循环 |
| sit | 10 / 10 FPS | 自然落座与稳定坐姿 |
| sleep | 10 / 6 FPS | 蜷缩、缓慢呼吸和轻微耳动 |
| happy | 16 / 16 FPS | 抬头、尾巴反馈和克制伸展 |
| dragged | 8 / 12 FPS | 被提起后的自然悬垂姿态 |

正式素材必须保持同一主体身份和真实结构；单张照片的缩放、旋转或上下抖动不视为动画素材。
