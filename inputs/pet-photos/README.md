# 猫咪照片投递目录

请把同一只猫的原始照片直接放在此目录。不要提前抠图、加滤镜、拼接或压缩。

最低需要以下 6 张：

1. `01-front-face.*`：正脸近照，用于锁定眼睛、鼻子和额头花纹。
2. `02-left-profile.*`：左侧面，完整头身轮廓。
3. `03-right-profile.*`：右侧面，完整头身轮廓。
4. `04-standing-body.*`：站立全身，耳朵、四爪和尾巴完整。
5. `05-sitting-body.*`：自然坐姿全身。
6. `06-marking-detail.*`：最有辨识度的脸、背部或尾巴花纹。

推荐额外提供：连续走路照片、背面、尾巴细节、肉垫、开心/张嘴表情。每个角度可以提供 2–3 张，清晰度优先于数量。

拍摄要求：

- 柔和自然光，避免强逆光、闪光灯和浓重阴影。
- 背景尽量简单，并与毛色有明显色差。
- 相机尽量与猫身体同高，避免广角畸变。
- 单边不低于 1500 像素，无运动模糊。
- 保留原始 JPG/PNG/HEIC；不要提交社交软件截图。

此目录中的实际照片会被 Git 忽略，不会进入开源仓库。
